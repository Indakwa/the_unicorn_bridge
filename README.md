# 🦄 The Unicorn Bridge

A mobile-first game created for **JS13KGames 2026**.

Build a rainbow bridge, one color at a time, and help the unicorn make it home.

## 🎮 How to Play

Build the rainbow bridge one color at a time and help the unicorn reach the end.

- Look at the required color.
- Swipe that color upward.
- Avoid the wrong colors.
- Don't let the timer run out.
- Collect ❤️ Hearts for extra lives.
- Collect 🥈 Silver bubbles for bonus points.
- Complete the rainbow to extend the bridge.
- Help the unicorn make it home.

## 📱 Platform

Designed for **mobile and touch interaction**.

For the best experience, play on a phone.

## 🛠️ Built With

- HTML5 Canvas
- Vanilla JavaScript
- CSS
- Web Audio API

No external game libraries are used.

## 📦 JS13KGames

Created as an entry for the **JS13KGames 2026** competition.

The game is packaged and minified to meet the **13 KB** competition limit.
